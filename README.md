# Leonida Deduction Board

An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its
official name, description and grade, a checklist saved in the browser, export and import, filters by grade,
kind and status, a spoiler setting that hides story trophies until they are earned, a roadmap to the platinum,
the missable trophies flagged, and a guide to each trophy in this app's own words that quotes the official
description it reads.

Open `app/index.html` in a desktop browser. Nothing is fetched: the files work with the network off, and the data
is a plain script (`app/data/data.js`, generated by `gen.mjs`).

Sources: the official PlayStation 5 trophy list for names, descriptions and grades. Guides are the author's own,
built from those official descriptions and the game's structure; where the official text is only a hint (the
hidden trophies), the guide says so instead of inventing a location.

MIT licensed. Screenshots in `screenshots/` are real renders of the app, taken with headless Chrome at 1280 px.
